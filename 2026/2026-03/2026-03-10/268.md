problem: missing number

given an array nums containing n distinct numbers in the range [0, n] return only the number in the range that is missing from the array.

i did it the most simplest way using a for loop however the time complexity is terrible.

O(n^2) solution:
```python
class Solution(object):
    def missingNumber(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        for i in range(len(nums) + 1):
            if i not in nums:
                return i
        
```

thinking harder about this, to implement a solution with O(n) time comlexity I would have to use some bit manipulation trick.

i could use a hashset to store the digits we've come across, and if the number isn't in the set then return it.
this uses O(n) space though.

using hashset:
```python
class Solution(object):
    def missingNumber(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        hashset = set(nums)
        for i in range(len(nums) + 1):
            if i not in hashset:
                return i


```

now, for the bit manipulation solution. looking at the answers it says to use bitwise XOR.
the trick with XOR is that when you xor a number with itself, you end up with 0. 
when you xor a number with 0, you end up with your original number.

doing this, we can xor each number of the range of numbers with the numbers in the list, and whatever number is left we return.

**most optimised solution with XOR**
```python
class Solution(object):
    def missingNumber(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        xorr = len(nums)
        for i in range(len(nums)):
            xorr ^= i ^ nums[i]
        return xorr

```
