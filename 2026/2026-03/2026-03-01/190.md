problem: reverse bits

this problem is asking us to reverse the bits of a given 32 bits signed integer

i know that i need to convert the given integer into binary, then somehow reverse the bits in there. i could convert the binary representation into string, then loop through it in reverse?

this runtime complexity is terrible but it works.
```python
class Solution(object):
    def reverseBits(self, n):
        """
        :type n: int
        :rtype: int
        """
        bin_rep = bin(n)[2:]
        string_of_bin = format(n, '032b')
        reversed_string = string_of_bin[::-1]
        
        return int(reversed_string, 2)
```
