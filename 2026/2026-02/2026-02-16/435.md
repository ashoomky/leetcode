we loop through the array starting from the second element as we're saving the first one to compare in a variable called previous_end. then we check, if they are not overlapping, then update the previous end to the current end. however if they are overlapping, then add 1 to the result and set the previous end to the minimum of the two ends becausewe want to keep the smaller interval as we removed the one that overlapped.
```python
class Solution(object):
    def eraseOverlapIntervals(self, intervals):
        """
        :type intervals: List[List[int]]
        :rtype: int
        """

        intervals.sort()
        result = 0
        previous_end = intervals[0][1]

        for start, end in intervals[1:]:
            if start >= previous_end:
                previous_end = end
            else:
                result += 1
                previous_end = min(previous_end, end)

        return result
```
