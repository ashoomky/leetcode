problem: jump game

return true if there is a possible way to reach the end of the array exactly, given each integer tell us the max at which you can skip / jump.

my first thought is to use recursion, however that would take way too long.

at each step we check whether the new calculated step is greater than our current one. we also make sure we check base cases - if the index is greater than max_reach then there is no way we will ever reach the end, thus return false.
```python
class Solution(object):
    def canJump(self, nums):
        """
        :type nums: List[int]
        :rtype: bool
        """
        max_reach = 0
        for i in range(len(nums)):
            if i> max_reach:
                return False
            if i == len(nums) -1:
                return True
            if i >= len(nums) -1:
                return False
            max_reach = max(max_reach, i + nums[i])
```
