problem: single number

find the element in the array that does not appear twice 

can use a hashmap to store the frequency of each element

oh that was straight forward...

it says you must implement a solution with a linear runtime complexity and use only constant extra space.

this solution uses linear runtime complexity of O(n) due to the for loops, however it doesn't use constant extra space because a hashmap takes up more than O(1) extra space.

```python
class Solution(object):
    def singleNumber(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        
        freq = {}
        for n in nums:
            if n in freq:
                freq[n] += 1
            else:
                freq[n] = 1
        
        for key, value in freq.items():
            if value == 1:
                return key
```

the proper solution to adhere to these requirements is to use a trick - xor.
by xoring the current result variable and our current number we're iterating over, we can cancel out the numbers that are pairs. for instance, if you xor 2 ^ 2 together, it becomes 0 because exclusive or means we only have output 1 for situations where both elements are not the same, hence the or. when we xor an element with 0, we will get the element we started with.

```python
class Solution(object):
    def singleNumber(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        
        result = 0
        for n in nums:
            result ^= n
        return result
```
