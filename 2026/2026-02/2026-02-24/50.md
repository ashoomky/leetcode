okay for the O(log n) time complexity solution we have to use a math identity to cut it in half.

the while loop works like this: since if the power is positive, we can destructure the bracket to be broken up into powers of 2, for example,
x^4 = (x^2)^2
thus, in this solution we are using the concept of expanding powers. any positive integer exponent n can be written in binary. so, we only multiply the powers corresponding to 1 bits.
every iteration we do `x *= x` because after using the 
current power of x (for the least significant bit), we square it to get to the next power of 2. 
we do `n //= 2` to move through the bits, which essentially shifts n's binary representation right by one bit. so we only multiply when the bit is equal to 1, which we are checking in the if statement within the while loop.

Example with n = 13 (binary 1101):

Iteration	n (decimal)	n (binary)	n % 2	Multiply result?	x (power)
1	        13	        1101	       1	Yes	                x^1
2	        6	        110	           0	No	                x^2
3	        3	        11	           1	Yes	                x^4
4	        1	        1	           1	Yes	                x^8

```python
class Solution(object):
    def myPow(self, x, n):
        """
        :type x: float
        :type n: int
        :rtype: float
        """

        if n == 0:
            return 1
        if n < 0:
            x = 1 / x
            n = -n
        
        result = 1
        while n > 0:
            if n % 2 == 1:
                result *= x
            
            x *= x
            n //= 2
        return result
```
