okay for the O(log n) time complexity solution we have to use a math identity to cut it in half.

the while loop works like this: since if the power is positive, we can destructure the bracket to be broken up into powers of 2, for example,
x^4 = (x^2)^2
so, in our loop we check first if n is odd. if it is odd, we times the result by x once, so that we can get an even number to destructure the power like shown above.
```python
class Solution(object):
    def myPow(self, x, n):
        """
        :type x: float
        :type n: int
        :rtype: float
        """

        if n == 0:
            return 1
        if n < 0:
            x = 1 / x
            n = -n
        
        result = 1
        while n > 0:
            if n % 2 == 1:
                result *= x
            
            x *= x
            n //= 2
        return result
```
