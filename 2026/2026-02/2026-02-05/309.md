problem: best time to buy and sell stock with cooldown

array prices where prices[i] is the price of a given stock on the ith day.

find max profit you can achieve. may complete as many transactions as you like (i.e. buy one and sell one share of the stock multipel times) but after you sell your stock, you cannot buy stock the next day (needs to cool down).

you must also always sell after you buy as you cannot buy stock simultaneously and own more than one at a time.

so at each step we either need to buy, sell or cooldown.

alrighty this is the recursive tle way:
```python
class Solution(object):
    def maxProfit(self, prices):
        """
        :type prices: List[int]
        :rtype: int
        """
        # own true: we own it
        def dfs(i, own):
            if i >= len(prices):
                return 0
            if own: # sell
                return max(prices[i] + dfs(i+2, False), dfs(i + 1, True))
            else: # buy
                return max(-prices[i] + dfs(i + 1, True), dfs(i + 1, False))

        return dfs(0, False)
            

```

class Solution(object):
    def maxProfit(self, prices):
        """
        :type prices: List[int]
        :rtype: int
        """
        memo = {} # stores the current max result at the current index
        # own true: we own it
        def dfs(i, own):
            if i >= len(prices):
                return 0
            if (i, own) in memo:
                return memo[(i, own)]
            if own: # sell
                memo[(i, own)] = max(prices[i] + dfs(i+2, False), dfs(i + 1, True))
            else: # buy
                memo[(i, own)] =  max(-prices[i] + dfs(i + 1, True), dfs(i + 1, False))
            return memo[(i, own)]

        return dfs(0, False)
