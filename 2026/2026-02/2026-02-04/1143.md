problem: longest common subsequence

given two strings (text1 and text2) return the length of the longest common subsequence. if none, return 0.

a subsequence of a string is a new string generated from the original string with some characters (can be none) deleted without changing the relative order of the remaining characters.

so this is basically the same as the array question

since we have two strings it would be best to recursively traverse both strings at the same time.

at each step we either decide to keep the next letter, or move on without it.

this is the recursive way that tle as we are exploring too many duplicate paths:
```python
class Solution(object):
    def longestCommonSubsequence(self, text1, text2):
        """
        :type text1: str
        :type text2: str
        :rtype: int
        """
        result = 0
        def dfs(i, j):
            if i >= len(text1) or j >= len(text2):
                return 0
            if text1[i] == text2[j]:
                return 1 + dfs(i + 1, j + 1)
      
            return max(dfs(i + 1, j), dfs(i, j + 1))
        
        return dfs(0, 0)
```

top down method:
```python
class Solution(object):
    def longestCommonSubsequence(self, text1, text2):
        """
        :type text1: str
        :type text2: str
        :rtype: int
        """
        memo = {}
        def dfs(i, j):
            if i >= len(text1) or j >= len(text2):
                return 0
            if (i, j) in memo:
                return memo[(i, j)]
            if text1[i] == text2[j]:
                memo[(i, j)] = 1 + dfs(i + 1, j + 1)
            else:
                memo[(i, j)] = max(dfs(i + 1, j), dfs(i, j + 1))
            return memo[(i, j)]
        
        return dfs(0, 0)
```

bottom up method:
the 2d array stores the length of the longest common subsequece. for example, dp[i][j] means text1[i:] from index i to the end, and text2[j] from index j to the end.
the dp table size is + 1 to each length because the extra row and column represent empty suffixes - so if either string is empty the LCS length is 0. so the last row and last column are all zeros. this avoids index out of bounds when we +1 to the index.
we go backwards because we need to fill in the table from bottom right to top left, to ensure that all needed values are already computed.
if we find a match, then we add 1; use the character so make dp[i][j] = 1 + dp[i+1][j+1], which adds the current character (+1) and the numbers we currently have computed (hence the i+1, j+1 as we are in a backwards for loop thus adding moves us to the right.)
in the case that our characters do not match, we have two choices - to either skip a letter on the first string, or the second string. 
then we return dp[0][0] as we have now accumulated the result at the start of the 2d array.
this time complexity is faster because we are using a 2d array and no recursion, giving us O(m * n) which are the dimensions of the 2d array.

```python
class Solution(object):
    def longestCommonSubsequence(self, text1, text2):
        """
        :type text1: str
        :type text2: str
        :rtype: int
        """
        dp = [[0 for i in range(len(text2) + 1)]
                for j in range(len(text1) + 1)]
        
        for i in range(len(text1) - 1, -1, -1):
            for j in range(len(text2) - 1, -1, -1):
                if text1[i] == text2[j]:
                    dp[i][j] = 1 + dp[i + 1][j + 1]
                else:
                    dp[i][j] = max(dp[i+1][j], dp[i][j+1])
        return dp[0][0]
```
