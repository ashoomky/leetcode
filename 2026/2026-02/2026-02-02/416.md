problem: partition equal subset sum

given an integer array nums, return true if you can partition the array into two subsets such that the sum of the elements in both subsets is equal or false otherwise.

if we find a subarray that is equal to half of the sum of total array, then the rest of the array is automatically the second subarray with the same sum. the entire array can also be considered as one subset, with the other being empty.

so at each index i, we decide whether to include the number or not.

we need to see if the current array is equal to half of the sum. but where do i store the current subarray we have?

top down solution:
this is pretty self explanatory! 
the memo hashmap stores whether you can get to the sum from the current index. it stores take or skip because if either way can reach halfway, then we make it true.

```python
class Solution(object):
    def canPartition(self, nums):
        """
        :type nums: List[int]
        :rtype: bool
        """
        self.total = sum(nums)
        self.half = self.total // 2
        if self.total % 2 != 0:
            return False
        
        memo = {} # stores either true or false at each index ?
        def dfs(i, current_sum):
            if current_sum == self.half:
                return True
            if i == len(nums) or current_sum > self.half:
                return False
            if (i, current_sum) in memo:
                return memo[(i, current_sum)]

            take = dfs(i + 1, current_sum + nums[i])
            skip = dfs(i + 1, current_sum)
            
            memo[(i, current_sum)] = take or skip

            return memo[(i, current_sum)]

        return dfs(0, 0)

```
