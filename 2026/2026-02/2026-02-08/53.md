my issue was trying to do recursion on the current and best variables which made my time complexity too large.
basically a greedy problem is a problem solving approach that makes the best possible choice at each small, immediate step to find a solution. it is called greedy because it focuses only on the immediate benefit without considering consequences of the current decision on future steps, and never reconsiders past choices.
```python
class Solution(object):
    def maxSubArray(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        best = nums[0]
        current = nums[0]
        for i in range(1, len(nums)):
            current = max(nums[i], current + nums[i])
            best = max(best, current)
        return best
```
