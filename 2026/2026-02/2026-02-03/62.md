```python
class Solution(object):
    def uniquePaths(self, m, n):
        """
        :type m: int
        :type n: int
        :rtype: int
        """
        grid = [[0] * n for _ in range(m)]
        rows, columns = len(grid), len(grid[0])

        # i = row, j = column
        def dfs(i, j):
            if i >= rows or j >= columns or i < 0 or j < 0:
                return 0
            if i == rows-1 and j == columns-1:
                return 1
            
            return dfs(i + 1, j) + dfs(i, j + 1) # down, right
        return dfs(0, 0)

```

to decrease the time complexity, as right now it's O(n^2) as it's exploring all paths, i will use top down memoisation to store the paths already explored.
in the memo hashmap i can store the number of valid paths from the current location (i, j).

```python
class Solution(object):
    def uniquePaths(self, m, n):
        """
        :type m: int
        :type n: int
        :rtype: int
        """
        grid = [[0] * n for _ in range(m)]
        rows, columns = len(grid), len(grid[0])
        memo = {} # store number of valid paths from current location

        # i = row, j = column
        def dfs(i, j):
            if i >= rows or j >= columns or i < 0 or j < 0:
                return 0
            if i == rows-1 and j == columns-1:
                return 1
            if (i, j) in memo:
                return memo[(i, j)]
            memo[(i, j)] = dfs(i + 1, j) + dfs(i, j + 1) # down, right
            
            return memo[(i, j)]
        return dfs(0, 0)


```
