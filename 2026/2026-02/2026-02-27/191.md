problem: number of 1 bits

my initial thought was to convert the given binary representation as a string, and then loop through it and store the number of ones in a variable. 

this works, except a more efficient solution (that aleck showed me) is to instead convert the given integer to binary as it is currently the integer type, then count the amount of ones in the new binary type.

```python
class Solution(object):
    def hammingWeight(self, n):
        """
        :type n: int
        :rtype: int
        """
        return bin(n)[2:].count('1')

```
