```python
class Solution(object):
    def lengthOfLIS(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        def dfs(i, j):
            if i == len(nums):
                return 0
            result = dfs(i + 1, j) # not include current element

            if j == -1 or nums[i] > nums[j]:
                result = max(result, 1 + dfs(i+ 1, i)) 
            return result
        return dfs(0, -1)
```

top down solution:
i is our current element, and j is our previous element. j = -1 means that we haven't chosen anything yet.
first we initialise a memo table of size n + 1, where n is the length of the nums. we do + 1 because j starts at -1, and ends at n - 1. so j = -1 is column 0, meaning j = n-1 will be column n. 
thus, memo[i][j+1] = the list length starting at i, with previous index j.
```python
class Solution(object):
    def lengthOfLIS(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums)
        memo = [[-1] * (n+1) for _ in range(n)]

        def dfs(i, j):
            if i == len(nums):
                return 0
            if memo[i][j + 1] != -1:
                return memo[i][j + 1]
            
            result = dfs(i + 1, j) # skipping current element

            if j == -1 or nums[j] < nums[i]:
                result = max(result, 1 + dfs(i + 1, i))
            memo[i][j+1] = result
            return result
        return dfs(0, -1)
```

**top down part 2:**
time complexity is really bad on this.
we no longer keep track of the previous index. 
we initialise a memo array where memo[i] stores the list length starting at index i. -1 means not computed yet.
the list is always initialised to be 1 first because the first element is always bound to be part of it.

```python
class Solution(object):
    def lengthOfLIS(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums)
        memo = [-1] * n

        def dfs(i):
            if memo[i] != -1:
                return memo[i]

            LIS = 1
            for j in range(i + 1, n):
                if nums[i] < nums[j]:
                    LIS = max(LIS, 1 + dfs(j))

            memo[i] = LIS
            return LIS

        return max(dfs(i) for i in range(n))
```
