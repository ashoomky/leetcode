problem: counting bits

given an integer n, return an array ans of length n + 1 such that for each i (0 <= i <= n), ans[i] is the number of 1's in the binary representation of i.

there should be some bit manipulation way to solve this but i'm going to try brute force my way to it first.

so for each incrementing element in the array (given the range n), we return in the index of the corresponding array how many one bits are in that number i's binary representation.

i did this:
```python
class Solution(object):
    def countBits(self, n):
        """
        :type n: int
        :rtype: List[int]
        """
        result = [0] * (n + 1)
        for i in range(n + 1):
            result[i] = bin(i)[2:].count('1')
        return result
        
```
however i do not think this solution is the most efficient in terms of time complexity. this gives us a time complexity of O(n log n) due to the built in count function that loops through each binary digit to count the number of ones.
