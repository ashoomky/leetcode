problem: hand of straights

hand of straights

alice has some number of cards she wants to rearrange the cards into groups os that each group is of size groupSize, and consists of groupSize consecutive cards

given an integer array hand where hand[i] is the value written on the ith card and an integer groupSize, return true if she can rearrange the cards, or false otherwise.

so we want groups of consecutive cards, and the size of the groups has to be the given argument groupSize. 

so at each choice we need to decide whether to include the current card in a group, or not.

given the array, we know that the minimum value should be the starting value of the group. it could also be the starting element for many groups if there's more than one of its card. to track the frequencies of each card we can store it in a hashmap.

hint 2 says to sort the hand array

had to look at solution because i got confused on how to loop through the hand to get the next consecutive card, but it makes sense they used another for loop within the original for loop with the range current card to card + groupsize so we get the range of the consecutive numbers we're supposed to have.

```python
class Solution(object):
    def isNStraightHand(self, hand, groupSize):
        """
        :type hand: List[int]
        :type groupSize: int
        :rtype: bool
        """

        freq = {}
        for i in range(len(hand)):
            if hand[i] in freq:
                freq[hand[i]] += 1
            else:
                freq[hand[i]] = 1
        
        hand.sort()

        for card in hand:
            if freq[card] == 0:
                continue

            for next_card in range(card, card + groupSize):
                if freq.get(next_card, 0) == 0:
                    return False
                freq[next_card] -= 1
                
            
        return True
```
