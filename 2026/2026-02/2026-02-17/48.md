okay so there are layers of squres, rotate those at a time.
make sure to save the top left in a temp variable so we can still access the number to rotate.

this was really confusing but the diagram helped.
it's kinda like a spiral - it moves and gets replaced at each iteration of the for loop. 
we minus / add i depending on what layer of the square we're currently in.
```python
class Solution(object):
    def rotate(self, matrix):
        """
        :type matrix: List[List[int]]
        :rtype: None Do not return anything, modify matrix in-place instead.
        """

        l, r = 0, len(matrix) - 1
        while l < r:
            for i in range(r - l):
                top, bottom = l, r
                # save top left
                top_left = matrix[top][l + i]
                # move bottom left into top left
                matrix[top][l + i] = matrix[bottom - i][l]
                # move bottom right into bottom left
                matrix[bottom - i][l] = matrix[bottom][r - i]
                # move top right into bottom right
                matrix[bottom][r - i] = matrix[top + i][r]
                # move top left into top right
                matrix[top + i][r] = top_left
            l += 1
            r -= 1
        
        
```
