problem: set matrix zeroes

given an m x n integer matrix, if an element is 0, set its entire row and column to 0's 

this could be done with dfs?

oh but we need to zero out the entire row and column, and dfs only works for this if we only need to go in one direction outwards on both sides.

we could instead do this with two passes, 
1. record where the original zeros are
    - if matrix[i][j] == 0, mark row i and j
2. zero out everything in those marked rows/cols
    - loop again, and if row i is marked or col j is marked, make it equal to 0.

i implemented the above solution but quickly realised that by storing the coordinates in an array, i could be zeroing more than i need to and overriding previous results.
to fix this i will store the rows and columns in separate hashsets.

```python
class Solution(object):
    def setZeroes(self, matrix):
        """
        :type matrix: List[List[int]]
        :rtype: None Do not return anything, modify matrix in-place instead.
        """
        rows, columns = len(matrix), len(matrix[0])
        marked_rows = set()
        marked_cols = set()
        for i in range(rows):
            for j in range(columns):
                if matrix[i][j] == 0:
                    marked_rows.add(i)
                    marked_cols.add(j)
        
        for i in range(rows):
            for j in range(columns):
                if i in marked_rows:
                    matrix[i][j] = 0
                if j in marked_cols:
                    matrix[i][j] = 0
        
```
