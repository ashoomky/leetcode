problem: insert interval

we are given an array of non-overlapping intervals where intervals[i] = [start, end]. this means that each element in the intervals array represents the start and end of the ith interval.
we are also given a new interval that represents the start and end of another interval.

insert new interval into intervals such that intervals is still sorted in ascending order by start, and intervals still does not have any overlapping intervals.

they do not overlap if the start of the first one is greater than the end of the new interval, and if the end of the first one is less than the start of the new one.

we can check if they overlap using the else statement.

in the else statement, we recalculate the new interval because they currently overlap and we need a new interval that we can add in order.
in the elif statement we set the newInterval to the next interval to shift it.
```python
class Solution(object):
    def insert(self, intervals, newInterval):
        """
        :type intervals: List[List[int]]
        :type newInterval: List[int]
        :rtype: List[List[int]]
        """

        result = []
        for start, end in intervals:
            if end < newInterval[0]:
                result.append([start, end])
            elif start > newInterval[1]:
                result.append(newInterval)
                newInterval = [start, end]
            else:
                newInterval[0] = min(start, newInterval[0])
                newInterval[1] = max(end, newInterval[1])
        result.append(newInterval)

        return result
```
