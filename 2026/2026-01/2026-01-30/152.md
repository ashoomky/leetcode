```python
class Solution(object):
    def maxProduct(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        result = nums[0]

        for i in range(len(nums)):
            current = nums[i]
            result = max(result, current)
            for j in range(i + 1, len(nums)):
                current *= nums[j]
                result = max(result, current)
        return result
```

wow there's a sliding window solution where it makes sure there's an even amount of negative values in the window so that the result would definitely be positive, or else it increases the window. okay wait this solution is so long what the flip.

the dp way for this solution is called kadane's algorithm which is adapted for products.

okay so...
a tricky thing with this problem is that negative numbers flip signs, and zero resets everything. (a small negative number can become huge if multiplied by another negative later)
thus, we can't just keep track of the best so far

at each index, we keep track of the current_max (max product ending at this index), and current_min (min product ending at this index). we keep track of minimum because a negative * negative = positive, so in case in the future we multiple the minimum by another negative we will obtain potentially even a bigger product than if the negative was multiplied by the current *positive* product.

we initialise the min and max at 1 because it doesn't affect multiplication.
result stores the best product seen so far.

in the for loop, we save the old maximum in a temporary variable.
then we update the current max - either extending the current max, current min or starting fresh from the current n. (by extending the current max i mean by multiplying the new value and seeing which one is the maximum.)

then for the current min, we either update to the minimum old temp, extended version of current minimum or n, our current number.
```python
class Solution(object):
    def maxProduct(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        result = nums[0]
        current_min, current_max = 1, 1

        for n in nums:
            temp = current_max * n
            current_max = max(n * current_max, n * current_min, n)

            current_min = min(temp, n * current_min, n)
            result = max(result, current_max)
        return result

```
