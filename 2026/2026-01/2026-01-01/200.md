**dfs solution:**
okay so we defined directions to make it easy to call dfs on every cell surrounding our current one.
we define a dfs function 
1. with base cases for when the indices are out of bounds and when the current cell is 0, return
2. make our current cell 0 to ensure we don't go back ot it
3. explore the four adjacent cells surrounding our current one by iterating through our directions arrayu
then outside of the dfs function, we call it on each of the cells that we encounter using a nested for loop iterating through the grid. if we encounter a cell that is equal to 1, we run dfs and increment the islands by 1.
```python
class Solution(object):
    def numIslands(self, grid):
        """
        :type grid: List[List[str]]
        :rtype: int
        """
        # up, down, right, left
        directions = [[1, 0], [-1, 0], [0, 1], [0, -1]]
        islands = 0
        rows, columns = len(grid), len(grid[0])
        def dfs(row, col):
            if row >= rows or row < 0 or col >= columns or col < 0 or grid[row][col] == "0":
                return 
            
            # making current island 0 to sink it so we don't go back
            grid[row][col] = "0"
            # exploring the four cells around our current one to see if it is still part of the group
            for direction_row, direction_col in directions:
                dfs(row + direction_row, col + direction_col)

        # running dfs only on the 1 we've encountered - the rest of the search will be carried out above
        for r in range(rows):
            for c in range(columns):
                if grid[r][c] == "1":
                    dfs(r, c)
                    islands += 1                
        
        return islands
        
```

**bfs solution**
we initiaite the same variables outside the bfs function as we did for dfs.
within the bfs function we initialise a priority queue, and set the current cell to 0. 
we then append the current coordinates to the queue as this is now the cell we want to explore from.
while queue is not empty, we extrapolate the row and column from the queue at the start, and loop through in all four directions from our current cell. we check that if any of these newly copmuted directions are out of bounds OR equal to 0. if they do, continue the loop and skip the iteration as we haven't found another 1. if not, then append the new column and row to the queue and set the new row and column to 0.
run bfs on each cell of the grid and return islands.
```python
class Solution(object):
    def numIslands(self, grid):
        """
        :type grid: List[List[str]]
        :rtype: int
        """
        islands = 0
        rows, columns = len(grid), len(grid[0])
        directions = [[0, 1], [0, -1], [1, 0], [-1, 0]]

        def bfs(r, c):
            q = deque()
            grid[r][c] == "0"
            q.append((r, c))

            while q:
                row, col = q.popleft()
                for direction_row, direction_col in directions:
                    new_row, new_col = direction_row + row, direction_col + col
                    if new_row < 0 or new_col < 0 or new_row >= rows or new_col >= columns or grid[new_row][new_col] == "0":
                        continue
                    q.append((new_row, new_col))
                    grid[new_row][new_col] = "0"

        for r in range(rows):
            for c in range(columns):
                if grid[r][c] == "1":
                    bfs(r, c)
                    islands += 1
        return islands
        
```
