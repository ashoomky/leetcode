top down solution:
use a cache (memo) to store the sums/paths we've already encountered. 
our calculation gives us two options to go to:
1. we calculate the new cost with the next house after the next one 
2. we skip the above option and go to the next house as the cost above would've been less.
by taking the max of either two options we ensure that at each step we choose the max cost to rob.

```python
class Solution(object):
    def rob(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums)
        memo = {}

        def dfs(i):
            if i >= n:
                return 0
            if i in memo:
                return memo[i]
            memo[i] = max(nums[i] + dfs(i + 2), dfs(i + 1))
            return memo[i]
        
        return dfs(0)
```
