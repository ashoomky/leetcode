so we have to return a list of grid coordinates where the rain water can flow from cell (r, c) to both the pacific and atlantic oceans.

so water can only flow to neighbouring cells if and only if the the neighbouring cells height is less than or equal to the current cell's height.

right so the solution is a bit confusing i folded and looked at it, but makes sense now.

two hashmaps to store the coordinates where water can flow outwards.
define a dfs function where we have r, c, visit (the hashmap depending on which cells we're running) and previous height so that we can check whether the current cell is less than the previous height. if it is, that means we would technically be going downhill and we can't do that as we're trying to get up. thus return.
then add the current coordinates to the hashmap, and run dfs again on each four directions.
then outside the dfs function run two for loops - through the columns, and through the rows.
then the rest is history!

```python
class Solution(object):
    def pacificAtlantic(self, heights):
        """
        :type heights: List[List[int]]
        :rtype: List[List[int]]
        """
        rows, columns = len(heights), len(heights[0])
        pacific, atlantic = set(), set()

        def dfs(r, c, visit, previous_height):
            if ((r, c) in visit or r < 0 or c < 0 
            or r == rows or c == columns 
            or heights[r][c] < previous_height):
                return
            
            visit.add((r, c))
            dfs(r + 1, c, visit, heights[r][c])
            dfs(r - 1, c, visit, heights[r][c])
            dfs(r, c + 1, visit, heights[r][c])
            dfs(r, c - 1, visit, heights[r][c])

        
        for c in range(columns):
            # loop for pacific ocean top
            dfs(0, c, pacific, heights[0][c])
            # loop for atlantic ocean bottom
            dfs(rows - 1, c, atlantic, heights[rows-1][c])
        
        for r in range(rows):
            # loop for pacific ocean left
            dfs(r, 0, pacific, heights[r][0])
            # loop for atlantic ocean right
            dfs(r, columns - 1, atlantic, heights[r][columns-1])
        
        result = []
        for r in range(rows):
            for c in range(columns):
                if (r, c) in pacific and (r, c) in atlantic:
                    result.append([r, c])
        return result
```
