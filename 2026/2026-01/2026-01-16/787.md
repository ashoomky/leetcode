problem: cheapest flights within k stops

i think this is another mst problem again.

which means we also need an adjacency list that contains the node as the key, and for the value we have [next node, weighted edge/price]

this is bellman ford solution algorithm implementation

basically we initialise an array filled with inifinity, and set the price of source to 0 as it requires no distance to travel there.
then, for the range of k + 1 (the number of stops we must make) we initialise a temporary prices list for a type of bfs search (this is just a copy of the infinity list)
then for each object in flights, we calculate the new price to get there. from our current node. if there is none, we continue (e.g. if the current node is infinity). 
now to check if the new price is less than what is already there: if the price of the source node plus the price of the current object is less than the price of the destination node of this object, we set the price of the dest node to our new one that is equal to less. then outside that for loop you set the array to the new temporary array and the loop goes back again for its second round of "bfs".

now when returning, we return -1 if the prices destination is equal to infinity because that means there is no possible way to get there. otherwise, return the price of the destination node given.

```python
class Solution(object):
    def findCheapestPrice(self, n, flights, src, dst, k):
        """
        :type n: int
        :type flights: List[List[int]]
        :type src: int
        :type dst: int
        :type k: int
        :rtype: int
        """
        prices = [float("inf")] * n
        prices[src] = 0

        for i in range(k + 1):
            temp_prices = prices[:]

            for s, d, p in flights: # source, destination, price
            #if no path, just continue
                if prices[s] == float("inf"):
                    continue
                if prices[s] + p < temp_prices[d]:
                    temp_prices[d] = prices[s] + p

            prices = temp_prices
        
        return -1 if prices[dst] == float("inf") else prices[dst]
```
