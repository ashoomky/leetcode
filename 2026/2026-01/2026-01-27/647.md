problem: palindromic substrings

return the amount of palindromic substrings within the given string

we can use some of the solution from yesterday - we can determine that a substring is a palindrome

woweeee this is using bottom up!
first i have two variables, middle and number which stores the middle index of the palindrome and the number of palindromes we have within this string respectively. 
result acts as the "middle" of the palindrome as we search left and right from the current result index.

the solution is basically the same as longest palindrome, except i got rid of the result_length variable as we don't need it as knowing the length of the string is redundant here. 
i also initialised a 2d array to indicate whether it is currently a palindrome, where the cell would be true if the index i to j (located in cell dp[i][j]) would be a palindrome.
so now we run a nested for loop, the outer one iterating left, and the inner loop iterating to the right of the index. then we do our checks - if the left and right characters are equal, and the current length of the substring is less than or equal to two OR the previous extension is true (checked from the 2d array, meaning that it is still a palindrome) then we set the current cell to true, indicating that s[i:j] is still a palindrome. increment number of palindromes by 1, because that would mean we would've found a palindrome !
```python
class Solution(object):
    def countSubstrings(self, s):
        """
        :type s: str
        :rtype: int
        """
        
        number = 0
        n = len(s)
        dp = [[False] * n for _ in range(n)]

        for i in range(n-1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j - i + 1 <= 2 or dp[i+1][j-1]):
                    dp[i][j] = True
                    number += 1
        return number
```
