ohhh its the edge that creates a cycle in the graph because the graph is initially acyclic, and a cycle is formed only after adding that edge. 

hint 2 says we can use the union-find (DSU) algorithm to create the graph from the given edges. while connecting the edges, if we fail to connect any edge, this is the redundant edge and return it.

hint 3 says to create an instance of the dsu object and traverse through the given edges. for each edge, attempt to connect the nodes using the union function. if the union function returns false, return that edge. 

alrighty so we need to initialise an empty list to keep track of the parent of each node.
and we also have a rank variable to store the size of each connected component, so we can update.
find function:
- we use path compression to make the lookup of each node's parent faster. 
- in our list, each ith position contains that node (i)'s parent.
- it returns the root parent of the connected component that the current node n belongs to.
- the if statement: if n is not its own parent, then it has a parent above it so we recursively call find() on its parent to keep going and find the root parent.
union function:
- if they share a parent, there's a cycle thus return false.
- now to update the ranks (component sizes) - if the rank of p1 is bigger than p2, add the size of the smaller component tot he bigger one and update the parent of p2 to be p1 as the p2 section is now part of p1.
then, run the union function on the two edges to see whether they share a parent.

```python
class Solution(object):
    def findRedundantConnection(self, edges):
        """
        :type edges: List[List[int]]
        :rtype: List[int]
        """
        n = len(edges)
        parent = [i for i in range(n + 1)] # parent of the ith node in position
        rank = [1] * (n + 1) #size of each connected component
        
        # find the parent of the given node
        def find(n):
            if n != parent[n]:
                parent[n] = find(parent[n])
            return parent[n]
            
        
        def union(n1, n2):
            # seeing if the nodes share a parent. if they do, there's a cycle and return false.
            p1, p2 = find(n1), find(n2)
            if p1 == p2:
                return False
            
            if rank[p1] > rank[p2]:
                parent[p2] = p1
                rank[p1] += p2
            else:
                parent[p1] = p2
                rank[p2] += p1
            return True


        for n1, n2 in edges:
            if not union(n1, n2):
                return [n1, n2]

        


```
