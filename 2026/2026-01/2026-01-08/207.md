solution

so it's an adjacency list problem.
oh so we create a hashmap with the courses and their prereq first.

firstly, we map each course to a list of their prerequisites.
then we initialise a hashmap called seen to add courses to when we are on them.
inside the dfs function, we have two base cases. if the course is in seen, we return False as that means we have come across a cycle.
and, if the list of prereqs for the current course we're on is empty, we return True because that means there's no more prereq's to fulfill and we can thus do all the courses !!
then we add the course to the hashset.
then we iterate through the prereq's of our current course and recursively call dfs. if it returns false, we immediately return false because that means we've already come across a cycle.
after going through all the courses, we then remove the course from the hashset because it means we were able to complete it with the prereq. we also need to make the prereq list of the current course in the hashmap empty because we have fulfilled the requirements. then return True.


```python
class Solution(object):
    def canFinish(self, numCourses, prerequisites):
        """
        :type numCourses: int
        :type prerequisites: List[List[int]]
        :rtype: bool
        """
        # mapping the prereqs to each course
        prereq_map = {i: [] for i in range(numCourses)}
        for course, prereq in prerequisites:
            prereq_map[course].append(prereq)

        seen = set()
        def dfs(course):
            if course in seen:
                return False
            if prereq_map[course] == []:
                return True
            
            seen.add(course)
            for prereq in prereq_map[course]:
                if not dfs(prereq):
                    return False
            
            seen.remove(course)
            prereq_map[course] = []
            return True
        
        for c in range(numCourses):
            if not dfs(c):
                return False
        return True
```
