problem: coin change

array has coins representing different denominations (value of each coin)
amount represents total amount of money

return the fewest number of coins that you need to make up that amount. if it cannot be made, return -1.

may have infinite number of each type of coin.

so then obviously we would start from the back of the array because we want to use the largest coins first.

well i looked at the solution and it makes a lot of sense now.

the key was using the remaining amount as the parameter, which makes sense as it lets us use the max coin for the new amount now instead of going from 0. 

bottom up solution seems pretty self explanatory as well.
```python
class Solution(object):
    def coinChange(self, coins, amount):
        """
        :type coins: List[int]
        :type amount: int
        :rtype: int
        """
        n = len(coins)
        memo = {}
        
        def dfs(amount):
            if amount == 0:
                return 0
            if amount in memo:
                return memo[amount]
            result = 1e9
            for coin in coins:
                if amount - coin >= 0:
                    result = min(result, 1 + dfs(amount - coin))
                memo[amount] = result
            return result
            
        minimum_coins = dfs(amount)
        if minimum_coins >= 1e9:
            return -1
        return minimum_coins
```
