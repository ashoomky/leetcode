```python
class Solution(object):
    def minCostClimbingStairs(self, cost):
        """
        :type cost: List[int]
        :rtype: int
        """
        
        def dfs(i):
            if i >= len(cost):
                return 0
            return cost[i] + min(dfs(i + 1), dfs(i + 2))
        
        return min(dfs(0), dfs(1))
        
```

top down solution:
the memo array shows where each position, memo[i] stores the min cost to reach the top from step i. 
if i is beyond the last step, return 0
if memo[i] has already been computed, return it
otherwise, we calculate the cost on that step and return the current cost of the step we're on.
```python
class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        memo = [-1] * len(cost)

        def dfs(i):
            if i >= len(cost):
                return 0
            if memo[i] != -1:
                return memo[i]
            memo[i] = cost[i] + min(dfs(i + 1), dfs(i + 2))
            return memo[i]

        return min(dfs(0), dfs(1))
```

bottom up solution (the best time complexity one and one that i used):
bottom up doesn't use recursion. instead, it goes from the bottom up in a for loop of the array, instead calculating the cost at each step to ensure that we are taking the minimum route.
dp[i] is the minimum cost to reach that step
step n is the top
we start the loop at 2 because step 0 and 1 are free, as that is where we essentially start.
the calculation is essentially going either one step or two steps. for `dp[i - 1] + cost[i - 1]`, we were already at step i - 1, and to step onto it we paid cost[i - 1]. we need to add both costs from the step before, and the step before that seperately because of how we are allowed to only skip either zero or one steps. then we move 1 step to i.
```python
class Solution(object):
    def minCostClimbingStairs(self, cost):
        """
        :type cost: List[int]
        :rtype: int
        """
        n = len(cost)
        dp = [0] * (n + 1)

        for i in range(2, n + 1):
            dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])
        
        return dp[n]
        
```
