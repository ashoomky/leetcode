then the dictionary represents the distance from the source to all nodes, initialised with infinity.

this is using djikstra's algorithm:
we have a dictionary with tuple values where the first value is the end node/destination, and the second value is the time it takes to get to that node.
then we have a min heap where it stores tuple values as well (weighted edge, node)
this min heap will include nodes that we come across in our neighbours of nodes and also haven't been processed yet / seen in the visit hashset.
then we have a visit hashset, to make sure we don't revisit, and time which is the result we're returning.
we then run a while loop while the heap is not empty; 
pop the top elements (the one with the LEAST weighted edge) and check if it is in visit. if not, add the node the visit hashset and recomputed the time to get to the current node (keep in mind our current weight parameter will have more time added on due to visits of past nodes). 
then, we traverse through all the neighbours of the current node and add them to the heap if they're not in the visit hashset. 
remember to push them with the new weighted value (we add the current weight onto the next because we took that path, which means we must add it.) 
then check, if the length of visit is the same as n, which is all the nodes in the graph, then we return the time. otherwise we have not managed to traverse all the nodes, thus return -1.

```python
class Solution(object):
    def networkDelayTime(self, times, n, k):
        """
        :type times: List[List[int]]
        :type n: int
        :type k: int
        :rtype: int
        """
        edges = defaultdict(list)

        for u, v, w in times:
            #(end node, time it takes)
            edges[u].append((v, w))
        
        # distance from source node to all nodes (weighted edge, node)
        minheap = [(0, k)]
        visit = set()
        time = 0

        while minheap:
            weight, node = heapq.heappop(minheap)
            if node in visit:
                continue
            visit.add(node)
            time = max(time, weight)

            for neighbour, w in edges[node]:
                if neighbour not in visit:
                    heapq.heappush(minheap, (weight + w, neighbour))
        
        if len(visit) == n:
            return time
        else:
            return -1
```
