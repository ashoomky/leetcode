```python
class Solution(object):
    def wordBreak(self, s, wordDict):
        """
        :type s: str
        :type wordDict: List[str]
        :rtype: bool
        """

        def dfs(i):
            if i >= len(s):
                return True
            for word in wordDict:
                if s[i:i + len(word)] == word:
                    if dfs(i + len(word)):
                        return True
            return False
             
        return dfs(0)
            
```
time to implement memoisation !

hm this is quite tricky.

top down solution:
base case: if we reach the end of the string, that means every previous choice worked meaning we return true.
if current index is in memo, return memo[i] as to prevent going down the same branch again.
then we loop through the words. if the word matches the string at index i, then we use it, if not skip it.
then we do recursion on the next chunk of string after our current one has been verified that it is part of the dictionary. then after all the recursive calls have occurred we reach the block of the if statement where it sets the current index to true in the dictionary. then we immediately return true as we have no other words to check. 
```python
class Solution(object):
    def wordBreak(self, s, wordDict):
        """
        :type s: str
        :type wordDict: List[str]
        :rtype: bool
        """
        memo = {}

        def dfs(i):
            if i >= len(s):
                return True
            if i in memo:
                return memo[i]
            
            for word in wordDict:
                if s[i:i + len(word)] == word:
                    if dfs(i + len(word)):
                        memo[i] = True
                        return True
            memo[i] = False
            return False
             
        return dfs(0)
            

```
