problem: decode ways

each number represents a letter in the alphabet.
however we have an issue - the same code can mean two different things: for example, 25 could be 2 and 5 OR 25.

we have to return the number of ways to decode it. if there are no valid ways to decode it, return 0. 

an integer with a leading 0 has no mapping to an alphabet, thus is not valid.

so does this mean that any string with a 0 is invalid?
nah because if we have 1011 that still could count as 1, 11, or 1, 1, 1.
and we just disregard the 0 i think

right so there should be a decision tree for the possible combinations, need to derive a recurrence relation for it.

`return dfs(i + 1) + dfs(i + 2)`

this is the recurrence relation as we can either have the possibility of one digit, or two digits defining the code.

have a check -  if the number is a 0, or has a leading 0, or is not a valid two digit number then we return 0.

okay so the brute force (recursive) way to do this problem leads to a tle, but this is the solution:
```python
class Solution(object):
    def numDecodings(self, s):
        """
        :type s: str
        :rtype: int
        """

        def dfs(i):
            if i >= len(s): 
                return 1
            if s[i] == '0':
                return 0
            res = dfs(i + 1)
            if i < len(s) - 1:
                if (s[i] == '1' or
                   (s[i] == '2' and s[i + 1] < '7')):
                    res += dfs(i + 2)

            return res
        
        return dfs(0)
        
```

the top down solution - we cache the answer the first time we compute it.

the dp hashmap contains how many times you can encode s[i:] for a given dp[i].
we have our usual checks at the start, so if the index is in dp, then we know that we have already checked how many ways it can be decoded. 
obviously 0 is not a valid letter to map, so we return 0. 
then we store the next recursive value in a variable, and check that the next value is valid (less than 26). if so, then add that to the result (dfs(i+2)). set dp[i] to result as that is the new value from where we are, as we have added the next value from the next index.
then, return the result. 

top down method:
```python
class Solution(object):
    def numDecodings(self, s):
        """
        :type s: str
        :rtype: int
        """

        dp = {len(s): 1} # empty string has only 1 decoding
        def dfs(i):
            if i in dp:
                return dp[i]
            if s[i] == "0":
                return 0

            result = dfs(i + 1)
            if i < len(s) - 1:
                if (s[i] == '1' or (s[i] == '2' and s[i+1] < '7')):
                    result += dfs(i + 2)
            dp[i] = result
            return result
        return dfs(0)
        
```
