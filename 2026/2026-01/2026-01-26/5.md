problem: longest palindromic substring

given a string s, we need to return the longest palindromic substring s.

so return the longest possible version of a palindrome in the string as a substring.

i tried to do memoisation where i checked it at every single step whether it is a palindrome, and if not then remove the added letter. however in retrospect this will not work because we cannot immediately assume after each step that is not a palindrome, because we don't know if the next letter added will actually create symmetry or not.

omg hint 2 is so smart it says to treat the current char as the middle of the palindrome and extend left and right to see if they match. we do need to take into account even-length and odd-length palindromes though.

to find the even length, can expand from two indicies (treat two as the center, i and i + 1). 

okay i folded the brute force solution is actually using two pointers but that gives a time complexity of O(n^3).

the dp solution uses the bottom up method, tabular something something. 
we iterate in a for loop starting from the end of the string, and also another nested for loop that decrements the counter every iteration.
if the characters are equal, and the length of the palindrome is less than or equal to 2 OR the 2d matrix value dp[i+1][j-1] is true (to check that the characters before are also palindromic), then we set the current value to true. then we check if the result length is less than the current length. if so, update to the new length and also update the current result index to i, as that's what we're treating as the middle of the palindrome.
then we return the indexed segment of string that is the largest palindrome using our variables.

the 2d array indicates whether the substring i:j is a palindrome. the first index is i, where it starts, and the second is j, where it ends.
the dp[i+1][j-1] comes from shrinking both sides, to check whether the string before it is a palindrome, which we would need it to be if we want to continue.
the index i goes left, and index j goes right.

```python
class Solution(object):
    def longestPalindrome(self, s):
        """
        :type s: str
        :rtype: str
        """
        result_length, result = 0, 0
        n = len(s)
        dp = [[False] * n for _ in range(n)] # array to check if it is a palindrome
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j] and (j-i <= 2 or dp[i+1][j-1]):
                    dp[i][j] = True
                    if result_length < (j - i + 1):
                        result = i
                        result_length = j - i + 1
        
        return s[result:result_length + result]
```
