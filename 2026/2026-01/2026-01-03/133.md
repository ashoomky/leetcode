okay dfs solution: simpler than one would think!
we have a hashmap that maps the old nodes to the new ones. this is important for distinguishing whether a clone of a node has already been made, and if it has been then we just connect it to the copy there.

we then define a dfs function, and have a base case checking if the current node we have is already in the hashmap. if it is, then we return the copy of it because we don't need to create a copy of the node again.

else, we create a copy, document it in the hashmap and iterate through its neighbours. within iterating through each neighbour of the current node, we recursively append the copy of the node to the current node's neighbor list. this works because our dfs function returns the copy of the node, so by calling it it just appends the copy. then we return copy!

```python
"""
# Definition for a Node.
class Node(object):
    def __init__(self, val = 0, neighbors = None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []
"""

class Solution(object):
    def cloneGraph(self, node):
        """
        :type node: Node
        :rtype: Node
        """

        old_to_new = {}

        def dfs(node):
            if node in old_to_new:
                return old_to_new[node]
            
            copy = Node(node.val)
            old_to_new[node] = copy
            for neighbor in node.neighbors:
                copy.neighbors.append(dfs(neighbor))
            return copy
        
        if node:
            return dfs(node)
        return None
```
