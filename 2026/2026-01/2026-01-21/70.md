problem: climbing stairs (dp)

how many distinct ways can you climb to the top of the stairs if each time you can either climb 1 or 2 steps?

this problem could be solved with back tracking.

i tried to use recursion to solve this, however it tle

```python
class Solution(object):
    def climbStairs(self, n):
        """
        :type n: int
        :rtype: int
        """
 
        def backtrack(steps_left):
            if steps_left == 0:
                return 1
            if steps_left < 0:
                return 0
            
            return backtrack(steps_left-1) + backtrack(steps_left - 2)
         
        
        return backtrack(n)
```

i now realise that using recursion takes too long as the time complexity of this solution is O(n^2).

hint 1 says to try avoid repeated work of calling recursion more than once with same parameters?

hint 2 says to use memoisation to avoid repeated work.
they say to create an n sized array cache to store the results of recursive calls. when the recursion is called with specific parameters, return the stored value if it has already been computed.

dude what
this method is called memoization - bottom up dynamic programming. essentially the brute force way is to have a binary tree that goes through each possible combination like i did above, however this solution TLE as we are often traversing the same paths multiple times, unnecessarily. 
so, to fix this issue we instead store the results from the same tree segment in an array - or in this case two variables as we only need access to the next two variables. we go from the bottom, and since there is only one way to get to the top of the stairs for each second to last and last stair, we initialise the two variables to one. then, we iterate through the stairs (in theory in reverse because we're starting with the end, hence the variables being equal to the amount of ways we can get to the end FROM the end)
iterate through the stairs from the end and sum the two variables together, while shifting them left.  then return one as that will be the final result of all the ways we can get to the stairs given we take one or two steps.

```python
class Solution(object):
    def climbStairs(self, n):
        """
        :type n: int
        :rtype: int
        """
 
        one, two = 1, 1
        for i in range(n - 1):
            temp = one
            one = one + two
            two = temp
        return one
```
