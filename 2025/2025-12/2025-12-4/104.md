hint 2 says we use DFS algorithm to find the max depth of a binary tree starting from root. for the subtrees in left and right from root, calculate their max depths recursively going through left and right subtrees. we return 1 + max(leftDepth, rightDepth) OHH that's how you find the max. and plus one because the root.

```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution(object):
    def maxDepth(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: int
        """

        if not root:
            return 0
       
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```
