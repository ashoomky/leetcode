first we have the base case that returns if we have the word (when the number letter we're on is equal to the length of the given word)
this works because our next conditional check checks if the indices are out of bounds, but also checks that the current letter we're on matches the same positioned letter in the input word we're trying to find. so if this condition isn't fulfilled it will already return False, therefore making sure that the word is equal when we do the first check.

we use a hash set to track whether we've seen this letter before because we don't want duplicates. we then assign the recursive calls to a variable result as it returns a boolean, and run the algorithm on the 4 neighbouring letters from the current cell. the  conditional checks will catch out of bounds indices.

then after all the recursive calls we remove r, c from the hashset because that's how backtracking works, and return result.

```python
class Solution(object):
    def exist(self, board, word):
        """
        :type board: List[List[str]]
        :type word: str
        :rtype: bool
        """
        rows, cols = len(board), len(board[0])
        seen = set()

        def dfs(r, c, i):
            if i == len(word):
                return True
            
            # conditions to check if the index and results are still valid
            if (min(r, c) < 0 or r >= rows or c >= cols or word[i] != board[r][c] or (r, c) in seen):
                return False
            
            seen.add((r, c))
            # up, down, right, left
            result = (dfs(r + 1, c, i + 1) or
                    dfs(r - 1, c, i + 1) or
                    dfs(r, c + 1, i + 1) or
                    dfs(r, c - 1, i + 1))
            seen.remove((r, c))
            return result
        
        for r in range(rows):
            for c in range(cols):
                if dfs(r, c, 0):
                    return True
        return False
```
