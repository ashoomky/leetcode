use the inbuilt heapq function to use the priority queue data structure. in a minimum heap which is what we used here, the elements will be increasing in value as you go down. we used a minimum heap for this question as we manipulated the heap to always be the length of k largest numbers, so that to access the kth largest number you can just access the minimum value of that heap. you can see that i did that below using the condition `while len(self.min_heap) > self.k:`. 

```python
class KthLargest(object):

    def __init__(self, k, nums):
        """
        :type k: int
        :type nums: List[int]
        """
        self.k = k
        self.min_heap = nums
        heapq.heapify(self.min_heap)
        while len(self.min_heap) > self.k:
            #since it's a min heap, will always pop the minimum element
            heapq.heappop(self.min_heap)
        

    def add(self, val):
        """
        :type val: int
        :rtype: int
        """
        heapq.heappush(self.min_heap, val)
        if len(self.min_heap) > self.k:
            heapq.heappop(self.min_heap)
        return self.min_heap[0]
```
