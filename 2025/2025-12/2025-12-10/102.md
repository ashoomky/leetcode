problem: binary tree level order traversal

given the root of a binary tree, return the level order traversal of its nodes values, from left to right. 
basically format is: [[first level], [second level], [third level], ...]

a binary tree is where each node has at most two children, and none have only one child.

i can recursively call the function to find the values of the node at each leaf and then append to a list. however how do we know which sublist to append to?

well traversing it is easy, it's just finding the structure of the list that's hard

i'm also appending None which is not a good thing either.

well hint 2 says to use bfs to traverse the tree level by level, which makes sense. bfs uses a queue data structure to achieve this.
at each step of bfs, we only iterate over the queue up to its size at that step. then, take the left and right child pointers and add them to the queue. this allows to explore all paths simultaneously.

i'm a bit stumped on how to use queues for this.

wait there's a dfs solution and its exactly what i was thinking i just didn't write it down; it was to create a dfs function and pass in the depth as a counter/parameter and append to that index of the list everytime we traverse down another level. 

dfs solution:
```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution(object):
    def levelOrder(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: List[List[int]]
        """

        
        result = []
        def dfs(node, depth):
            if not node:
                return None
            # checking if we need to initialise a new list for the nodes at the new depth
            if len(result) == depth:
                result.append([])
            result[depth].append(node.val)
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)
        
        dfs(root, 0)
        return result

```

now to learn the bfs solution:
you initialise a queue using "collections.deque() and a result list to store the result in. then we append the root first to get it in the queue, and then run a while loop while the queue is not empty. in this solution the queue length is used as an indicator of how many nodes to append to the list for each level. so we then get the length of the queue, and initialise the level list. then we run through the length of the queue in a for loop and append each value to the level list, then append the left and right nodes of the current node to the queue. this won't affect how many times we run through the for loop as we have already initialised the queue length, so this will be considered only after the previous length has been run through. oh and don't forget to pop the first element from the queue at the start of the for statement so that the while loop while stop running once we have gone through all the nodes in that level. 
finally, we append the level list to the result and return result which would give us the correct answer!
```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution(object):
    def levelOrder(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: List[List[int]]
        """
        
        result = []
        queue = collections.deque()
        queue.append(root)

        while queue:
            # making sure we go one level at a time
            queue_length = len(queue)
            level = []
            for i in range(queue_length):
                node = queue.popleft()
                if node:
                    level.append(node.val)
                    queue.append(node.left)
                    queue.append(node.right)
            if level:
                result.append(level)
        
        return result
```
