problem: combination sum

return a list of all unique combinations of candidates where the chosen numbers (number in the unique combination) sum to target.

same number may be chosen from candidates an unlimited number of times.
two combinations are unique if the frequency of at least one of the chosen numbers is different.

our base case would be when we reach the end of the list.

we stop extending the path when the sum of all our integers in the current unique combination equal to the target.

```python
class Solution(object):
    def combinationSum(self, candidates, target):
        """
        :type candidates: List[int]
        :type target: int
        :rtype: List[List[int]]
        """
        result = []
   
        def dfs(i, combination, total):
            if total == target:
                result.append(combination[:])
                return
            if i >= len(candidates) or total > target:
                return

            # taking the left branch - reusing the current value we're on, hence i stays the same 
            combination.append(candidates[i])
            dfs(i, combination, total + candidates[i])
            # pop to backtrack
            combination.pop()

            # skipping current value now
            dfs(i + 1, combination, total)

        dfs(0, [], 0)
        return result
```
