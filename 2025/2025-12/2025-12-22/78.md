okay backtracking is a search technique for solving complex problems by recursively exploring combinations of possible choices to arrive at a solution. undo the option if they lead to a dead end.

in this question i have to return all possible subsets (the power set).
the result must not contain duplicate subsets. 

backtracking algorithm usually goes like this:
1. choose node
2. explore - recursively move forward with choice
3. check validity - if choice leads to an invalid state, undo it (backtrack) and try another option
4. repeat - continue this process until all possibilities are explored or a valid solution is found

the difference between backtracking and recursion is that backtracking uses recursion to explore different possibilities, whereas recursion explores all possible paths without worrying if they are valid until the end.

thus the run time would be better.

the solution. 
we have a result array, and a subset array defined outside the dfs function.
we pass the index through the dfs function so we know when to stop iterating through the list and also what element to append.
our base case: if the index is out of bounds, this means that we have reached a leaf node and we have our current result as part of that decision, which we append a copy of our particular subset to the result array, then return. we append a copy of the subset because it is going to be modified, and we only want our leaf node, we don't want the subset array to be overwritten again and again and then appended to the result as it would give us an array of empty arrays.
then we have our first decision, which is to add values to the subset, and we call dfs again on the next element to see whether we want to append it.
then our next decision is to not add the value to the subset, which we just pop the element and continue running ont he next element.
the popping (second decision) is the backtracking, it removes the element we just added so we can try the other choice. 
ohh so when we return dfs we return to the function that we called from. think of it as a stack frame - once we get to dfs(3) and return, it gets popped off the stack and now we have dfs(2), so now i = 2.
```python
class Solution(object):
    def subsets(self, nums):
        """
        :type nums: List[int]
        :rtype: List[List[int]]
        """
        result = []
        
        subset = []
        def dfs(i):
            if i >= len(nums):
                result.append(subset[:])
                return

            # decision to add value to subset
            subset.append(nums[i])
            dfs(i + 1) # to run on the next element

            # decision to not add value to subset
            subset.pop()
            dfs(i + 1)
        
        dfs(0)
        return result
```
