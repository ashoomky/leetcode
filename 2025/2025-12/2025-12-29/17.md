problem: letter combinations of a phone number

so we are given a string containing digits from 2-0.
we have to return all possible letter combinations that the number could represent.

my first thought is to use a hashmap with the number as the key, and a list of letters it correlates to. 

then, given the digits, we retrieve these lists and concatenate them together, giving us the set letters that we can use to then produce every single combination possible, with no duplicates.

okay a hashmap is the right way to go. except my concatenating of the list values is not going as smoothly as expected.

ah i see we use the hashmap as a decision tree (vis a vis hint 1) where at each step we have a digit, and select one of multiple characters to proceed to the next digit in the string digits. 

we use backtracking where we select a character from the hashmap's corresponding list value and process it, then backtrack to process another character. recursively iterate on the given string with index i. at each step we consider the letters from the hashmap corresponding to letter at ith index.

base case would be - first to initialise an empty string that represents the choices of characters throughout the current recursive path. when index i reaches end of string, we add current string to result list and return.
kind of like palindrome partition! 

oh i made a mistake - i defined the letters corresponding to be strings within a list, when i should be defining it just as a string chunk. interesting.

wait this is so clean

we create a hashmap with the corresponding character to letter.
we then run a backtracking algorithm.
1. base condition: check if the length of the temporary string is equal to the length of digits we have (because it always will have to be, since we need the combination with no duplicates). if so, append the temp to result.
2. then, for each character in the characters corresponding to the digit we are on, backtrack by recursively calling the function again and increment i (to get the next number in digits) and add the character.

```python
class Solution(object):
    def letterCombinations(self, digits):
        """
        :type digits: str
        :rtype: List[str]
        """
    
        
        values = {"2": "abc",
            "3": "def",
            "4": "ghi",
            "5": "jkl",
            "6": "mno",
            "7": "qprs",
            "8": "tuv",
            "9": "wxyz",
            }

        result = []

        def backtrack(i, temp):
            if len(temp) == len(digits):
                result.append(temp)
                return
            
            for c in values[digits[i]]:
                backtrack(i + 1, temp + c)

        if digits:
            backtrack(0, "")
        return result
```
