problem: validate binary search tree 

return true if the following binary tree is a binary tree by these definitions:
1. left subtree of a node only contains nodes with values less than the current node's value
2. the right subtree contains only nodes with values greater than the current nodes values
3. all the nodes must follow these properties

so my first thought is to use dfs to recursively traverse through the tree. 

i access the left and right nodes of the current node and make sure that the left and right nodes do exist first so we're not accessing the value of a NoneType.

help wait there are some conditions that just aren't working.
like what if there's a left node but no right node? 

okay hint 2 said to track an interval that defines the lower and upper limits for the node's value in that subtree.
hint 3 said when traversing through the left subtree, you update the max value limit because all the values in the left subtree must be smaller than current node. 

i passed the interval through as a parameter but i realised that would provide the same interval for the left and right subtrees which we do not want, because we are comparing different things in each subtree.

well then how do you define the interval without it restarting every recursive call? maybe passing it as a parameter is the right way to go but i just didn't do it right?

ohmydays it's actually so freaking simple.

they did pass the intervals through as parameters, except in the form of left, right not an array. 

then they compared the current node value with that interval, and if it isn't then return false.

and they updated the parameters based on what subtree they were going to next in the recursive call - if going to the left subtree then you update the right / max of the interval to be the current node val as you cannot have another value that is greater than the current value

and another issue i was having is that i wasn't passing through the infinity interval as a float.

```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution(object):
    def isValidBST(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: bool
        """

        def dfs(node, left, right):
            if not node:
                return True
            
            if not (left < node.val < right):
                return False
            
            return dfs(node.left, left, node.val) and dfs(node.right, node.val, right)

        return dfs(root, float('-inf'), float('inf'))
```
