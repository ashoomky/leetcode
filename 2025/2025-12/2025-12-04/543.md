hint 4 says to use dfs to calculate the height of the tree.
at each node, the subtrees will return their respective heights(left and right height)
then calculate the diameter at that node and store in global variable where the max diameter is.

we used dfs to calculate the diameter within it, and then return the max depth of the node on either side to use for the calculation recursively within the function. 
```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution(object):
    def diameterOfBinaryTree(self, root):
        """
        :type root: Optional[TreeNode]
        :rtype: int
        """
        self.diameter = 0 # make it self so it becomes a global variable

        # using dfs to calculate the height of the tree and return the diameter
        def dfs(root):
            if not root:
                return 0

            left = dfs(root.left)
            right = dfs(root.right)
            self.diameter = max(self.diameter, left + right)

            return 1 + max(left, right)
        
        dfs(root)
        return self.diameter
```
