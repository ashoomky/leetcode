okay instead of using an array we use a counter to keep track of the current node in ascending order of values, and when the count is equal to k then we store the node's value in a global variable and return that.

however since we are calling it recursively it will immediately get from the right subtree.

i initialised a counter variable to equal to k and decremented it until it reached 0, which then would give us our desired value. i ran dfs on the left subtree first to ensure we would get the most minimum value. 
```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution(object):
    def kthSmallest(self, root, k):
        """
        :type root: Optional[TreeNode]
        :type k: int
        :rtype: int
        """
        self.minimum = 0
        self.count = k

        def dfs(node):
            if not node:
                return 0
            
            dfs(node.left)
            self.count -= 1
            if self.count == 0:
                self.minimum = node.val
                return
            dfs(node.right)
            
        
        dfs(root)
        return self.minimum
```
