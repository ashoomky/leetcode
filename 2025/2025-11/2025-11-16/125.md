problem: find a valid palindrome

initial thought is to return the string == reversed string to see if they're equal 
but we have to get rid of punctuation, so traverse through the string and concatenate only letters to a new string then return the boolean statement on that string instead.

this is my solution but it only beats 24% of time complexity
```python
class Solution(object):
    def isPalindrome(self, s):
        """
        :type s: str
        :rtype: bool
        """
        new_string = ""
        for letter in s:
            if letter.isalpha() or letter.isdigit():
                new_string += letter.lower()

        return new_string == new_string[::-1]
```

okay hint 3 says to use the two pointer algorithm to find whether the first and last character are the same.

i looked at the solution for the two pointer solution that has a time complexity of O(n) and space complexity of O(1)

basically implement the alpha numeric comparison yourself, and take up less space. check if it is not an alphabet, then keep incrementing the pointer until a character is reached. for both pointers. then the pointer l and r will be compared and returns false if not the same.

```python
class Solution(object):
    def isPalindrome(self, s):
        """
        :type s: str
        :rtype: bool
        """
        l, r = 0, len(s) - 1

        while l < r:
            while l < r and not self.alphaNum(s[l]):
                l += 1
            while r > l and not self.alphaNum(s[r]):
                r -= 1
            if s[l].lower() != s[r].lower():
                return False
            l, r = l + 1, r - 1
            
        return True
        
    def alphaNum(self, c):
        return (ord('A') <= ord(c) <= ord('Z') or ord('a') <= ord(c) <= ord('z') or ord('0') <= ord(c) <= ord('9'))
```
