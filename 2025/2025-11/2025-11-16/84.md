problem: find the largest histogram rectangle area 

initial thought is to find the max element in the array, then find its next biggest element then combine the two at the same value to get the area. 
but we have to go through all values and find all of their areas because there could be a greater than combination of values.

okay maybe i can go through the array, find the area next to the current bar, store it in a decreasing monotonic stack and return the top value from the stack. 

hint 2 says to precompute the left and right boundaries for calculating the width of the rectangle when extending the height left and right. 
hint 3 says the area for the rectangle will be height[i] * (right - left + 1). they say use a data structure to find the left and right boundaries. stack? but how
hint 4 says use an increasing monotonic stack, but store indices instead of values and perform operations based on the indices. top of the stack will represent the smaller bar that we encounter while extending the current bar. 

looked at the solution

store index and height in the stack
when reached a height smaller than current stack height, before popping compute the area first, then pop top element off stack then append element. however, since the element can also be extended back, we say the index is actually the previous element because it can still be extended as part of the rectangle area.
leftover elements in the stack means it goes all the way to the end so compute the area.

```python
class Solution(object):
    def largestRectangleArea(self, heights):
        """
        :type heights: List[int]
        :rtype: int
        """
        max_area = 0
        stack = [] # pair of elements: (index, height)

        for i, h in enumerate(heights):
            start = i
            while stack and stack[-1][1] > h:
                index, height = stack.pop()
                max_area = max(max_area, height * (i - index))
                start = index # extend it backwards
            stack.append((start, h))
        
        for i, h in stack:
            max_area = max(max_area, h * (len(heights) - i))
        return max_area
```
