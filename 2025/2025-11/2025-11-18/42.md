problem: find how much rain water can be trapped in the gaps of the histogram. each bar has width 1

increment pointer. if gap between two solid bars (the height is different) then calculate the distance between and add to the rain water trapped.

hint 2: two greatest elements are the most important. find this by using min(height[l], height[r] - height[i])
hint 4: store the prefix max in one array from left to right, and the suffix max in another array by iterating right to left. then iterate through the input array with index i to calculate the total water trapped at each position using the formula: min(prefix[i], suffix[i]) - height[i].

watched the solution. the formula is used to calculate how much water can be stored directly above the current block we are on. then all the values computed are added to the result. have two pointers, one at the start and one at the end and only increment the left pointer / decrement the right pointer when the current index has a smaller height than the max of left / right.


```python
class Solution(object):
    def trap(self, height):
        """
        :type height: List[int]
        :rtype: int
        """

        if not height:
            return 0
        
        l, r = 0, len(height) - 1
        left_max = height[l]
        right_max = height[r]
        result = 0

        while l < r:
            if left_max < right_max:
                l += 1
                left_max = max(left_max, height[l])
                result += left_max - height[l]
            else:
                r -= 1
                right_max = max(right_max, height[r])
                result += right_max - height[r]
        return result
```
