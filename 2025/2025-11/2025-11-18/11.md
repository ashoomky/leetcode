problem: find the largest area of container with most water

can extend the area from any bar, as long as the last bar isn't shorter than the first bar.

using two pointers we can iterate through the array with a pointer at the start, and at the end. we need to find all possible combinations of area, and we can do that by using our two pointer algorithm as we did in past questions like 2 sum sorted. 
actually we can't do 2 sum sorted because it's not sorted sigh

issue: how to get all possibile combinations of areas ?
lowkey like valid palindrome? 

```python
class Solution(object):
    def maxArea(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        
        max_area = 0
        l, r = 0, len(height) - 1
        
        while l < r:
            if height[l] < height[r]:
                area = height[l] * (r - l)
                max_area = max(max_area, area)
                l += 1
            elif height[r] <= height[l]:
                area = height[r] * (r - l)
                max_area = max(max_area, area)
                r -= 1
        
        return max_area
```
