the solution is to use a set (which stores unique values, no duplicates) and store each value in there. when reached a value from the right pointer that is in the set of unique elements, then keep incrementing the left pointer until the duplicate is no longer in there. then update the set with the new element that r is pointing to, then calculate and return the max result by using the current right and left pointers. 
```python
class Solution(object):
    def lengthOfLongestSubstring(self, s):
        """
        :type s: str
        :rtype: int
        """
        l = 0
        unique_elements = set()
        res = 0
        for r in range(len(s)):
            while s[r] in unique_elements:
                unique_elements.remove(s[l])
                l+=1
            unique_elements.add(s[r])
            res = max(res, r - l + 1)
        return res
```
