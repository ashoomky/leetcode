basically, the solution comes in three statges:
1. using fast and slow pointers to find the first and second half of the list
2. reversing the second half of the list 
    a) set second_half variable to slow.next, so that's the new head for the second half of the list
    b) set slow.next to None, so that the list is fully seperated.
    when reversing the second half, keep track of the next node in a temporary variable so we can modify it and still go to the next node even though we killed the link
3. merge the two lists together! 
    a) head of first list is head, head of second list is previous (from reversing the list before)
    b) keep temporary variables to store the next elements of the current nodes in both lists, and set the next to the other list's respective node. 
    c) update the current nodes !!

```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution(object):
    def reorderList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: None Do not return anything, modify head in-place instead.
        """

        # finding midpoint (slow pointer)
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        
        second_half = slow.next
        # splitting the two lists by setting slow.next to None
        slow.next = None

        # reversing list
        previous = None
        while second_half:
            temp = second_half.next
            second_half.next = previous
            previous = second_half
            second_half = temp
        
        # merging lists
        first, second = head, previous
        while second:
            temp1, temp2 = first.next, second.next
            first.next = second
            second.next = temp1
            first = temp1
            second = temp2
```
