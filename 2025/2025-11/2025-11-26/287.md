oh so there are two distinct solutions, negative marking (the one the hints were getting to), and fast and slow pointers which is where the linked list comes into play.

floyd's algorithm:
the idea: each index is a node. nums[i] is the next pointer (to the corresponding index). since there are two different indices that point to the same value, this creates a cycle in the "linked list". 
now, to detect the cycle. slow moves 1 step at a time (slow = nums[slow]), and fast moves 2 steps at a time (fast = nums[nums[fast]])
next, we find the entrance of the cycle (which would be the duplicate number). once they meet, we reset slow to 0 and run the slow and fast pointers again at the same speed (1 step each). then the point where they meet again is the start of the cycle. this is because fast has not been reset and is part of the cycle, so it will meet with the slow pointer eventually at some point. 
```python
class Solution(object):
    def findDuplicate(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        slow, fast = 0, 0
        while True:
            slow = nums[slow] 
            fast = nums[nums[fast]]
            if slow == fast:
                break

        slow2 = 0
        while True:
            slow = nums[slow]
            slow2 = nums[slow2]
            if slow == slow2:
                return slow
```
