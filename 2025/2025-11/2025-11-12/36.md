use conditional if statement - if we find the current element in the list of the index associated to that row or column we are currently in, return false. if we find the current element in the square where the key of the square in the hashmap is a tuple indicating what row and column the box is in (treat the box as one element)

*i used a new function called defaultdict(set) where it creates a dictionary object and creates keys that does not exist yet and assigns them empty sets, that way we can do the checks before adding into the dictionary. to add to these keys, do .add()

```python
    class Solution(object):
    def isValidSudoku(self, board):
        """
        :type board: List[List[str]]
        :rtype: bool
        """
        row = defaultdict(set)
        col = defaultdict(set)
        box = defaultdict(set)
 
        for r in range(9):
            for c in range(9):
                if board[r][c] == ".":
                    continue
                if (board[r][c] in row[r] or board[r][c] in col[c] or board[r][c] in box[(r // 3, c // 3)]):
                    return False

                row[r].add(board[r][c])
                col[c].add(board[r][c])
                box[(r // 3, c // 3)].add(board[r][c])

        return True


```
