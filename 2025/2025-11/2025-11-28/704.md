**solution:**(to iteratively call binary search)
we're going to have two pointers, l and r.
always look at the halfway point between l and r.
ask if it's smaller or larger than the target (since sorted, everything to the left will be less than and everything to the right will be greater than).
the next sub array is everything to the right/left of the element, excluding the current element we're on.

```python
class Solution(object):
    def search(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        l, r = 0, len(nums) - 1
        while l <= r:
            m = (l + r) // 2
            if nums[m] > target:
                r = m - 1
            elif nums[m] < target:
                l = m + 1
            else:
                return m
        return -1
```
