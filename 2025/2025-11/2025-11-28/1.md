re explaining the solution for active recall: we have a dictionary where we store the number as the key, and its index as the value. then we check if target - current number (nums[i]) is in the dictionary, and if it is then we've found a matching pair that adds to the target and we can now return the two indices - the current index we're on, and the value of the number in the dictionary!
```python
class Solution(object):
    def twoSum(self, nums, target):
        my_dict = {}

        for i in range(len(nums)):
            if target - nums[i] in my_dict:
                return [i, my_dict[target - nums[i]]]
            my_dict[nums[i]] = i

```
