i ended up using 3 for loops, and used a list as the value where the first index is the frequency of the letter in the first word, and the second index is the frequency of the letter in the second word. then check each value(list) in the dictionary to see if they are equal. if not equal, return false because that means they don't have the same amount of letters and therefore not an anagram.

```python
    class Solution(object):
    def isAnagram(self, s, t):
        """
        :type s: str
        :type t: str
        :rtype: bool
        """

        letter_freq = {}

        if len(s) != len(t):
            return False

        for letter in s:
            if letter in letter_freq:
                letter_freq[letter][0] += 1
            else:
                letter_freq[letter] = [1, 0]
         
        for letter in t:
            if letter in letter_freq:
                letter_freq[letter][1] += 1
            else:
                letter_freq[letter] = [0, 1]

        for value in letter_freq.values():
            if value[0] != value[1]:
                return False
        return True
```
