after a whopping 5 hours and some food i looked at the solution, watched the video and i understand now.
basically we keep a dictionary of all the different letters we encounter with a counter associated with it. if we encounter that letter, we increment its counter. then we do a while loop to check whether the current letters that can be replaced is greater than k. if so, then we keep incrementing the left pointer until that is not true. the formula length of string - current max frequent letter gives us the amount of letters that can currently be replaced within that window. if so, then decrement the left pointer character count in the hashmap as it won't be part of the window anymore, and also increment the left pointer by one. once we've reached a window where the condition is satisfied and we can actually replace the amount of characters k times, then calculate the max substring compared with what is currently stored, and return once for loop is done.
```python
class Solution(object):
    def characterReplacement(self, s, k):
        """
        :type s: str
        :type k: int
        :rtype: int
        """

        l = 0
        count = {}
        res = 0

        for r in range(len(s)):
            count[s[r]] = 1 + count.get(s[r], 0)
            # checking for if the amount of elements we can replace is greater than the given number 
            while (r - l + 1) - max(count.values()) > k:
                count[s[l]] -= 1
                l += 1
            res = max(res, r - l + 1)
        return res
```
