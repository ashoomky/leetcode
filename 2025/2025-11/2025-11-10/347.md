problem: given an array, return the number that is most frequently shown in the array. return up to k numbers given

we have to iterate through the loop, which gives us O(n).
use a hash map to store the frequency of each integer.
reverse sort the dictionary by values (although i don't know the time complexity of that)
and return however many k numbers we want in a list from the start of the list by indexing.

however when i access the values and sort in reverse i have no way of accessing the key its associated with anymore.

i cannot code up how to reverse sort a dictionary by value without asking google so i guess i've gotta think of another way because in an interview i would not be able to ask google how to do that.

also reversing a dictionary technically is only a temporary fix to the problem , because dictionaries are technically unordered and would only appear ordered if they were added to the dictionary in reverse order.

i ended up sorting it in a list of tuples using lambda to sort by the second value as that is the frequency, then access the key and return however many specified by integer k. i initially reversed it and accessed the values at the start, but my runtime ended up being really bad so i scrapped the reversing and just accessed the list from the back as it would have the most frequent values there.

```python
    class Solution(object):
    def topKFrequent(self, nums, k):
        """
        :type nums: List[int]
        :type k: int
        :rtype: List[int]
        """
        freq = {}
        for n in nums:
            if n in freq:
                freq[n] += 1
            else:
                freq[n] = 1
        sorted_freq = sorted(freq.items(), key=lambda x:x[1])
        return [key[0] for key in sorted_freq[-k:]]
```
