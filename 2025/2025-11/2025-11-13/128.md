problem: return length of longest consecutive elements sequence

requirement: must run in O(n) time

we are given an input array that contains scattered, unordered elements and we have to find the longest sequence of consecutive numbers.

how to keep track of a number that COULD be consecutive but shows up earlier in the array? gotta store it somewhere so we can compare it with the current element, can't disregard it.

for loop to go through the array, store the value in a hashmap with its index as the key.
then have another for loop going through the hashmap comparing the current value with value in hashmap. access it using index and up the counter.

but we don't really need to keep track of the actual value, we just return the length.
can't use sorted() because that gives runtime of O(n log n) and we can only have runtime of O(n)

first solution was to store the values in a dictionary using their actual value as the key which i thought would somehow sort the values in order but it in fact does not.

biggest issue we have to overcome is knowing how to concatenate a sequence with a smaller value at the end

i could group consecutive sequences in the order we go in the input list, then check for individual elements that could be part of a sequence before? but how tf do i do that

hint 2: instead of forming a sequence for every number, we should only consider numbers like 1 and 10 given an array [1,2,3,10,11,12]
hint 3: build a sequence in hashmap if and only if it is the start of a sequence (e.g. num - 1 does not exist in the input array)

aleck's hint: store the actual number as the key, and the counter as the value. then check if nums[i] - 1 or nums[i] + 1 is in array, if so then increment those counters.

```python
    class Solution(object):
    def longestConsecutive(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """

        sequences = {}

        if not nums:
            return 0

        for n in nums:
            if n in sequences:
                continue
            elif n - 1 in sequences and n + 1 in sequences:
                current = sequences[n - sequences[n-1]] + sequences[n + sequences[n+1]] + 1
                # updating
                sequences[n + sequences[n+1]] = current
                sequences[n - sequences[n-1]] = current
                sequences[n] = current
            elif n + 1 in sequences:
                sequences[n] = sequences[n+1] + 1
                sequences[n + sequences[n+1]] = sequences[n]
            elif n - 1 in sequences:
                sequences[n] = sequences[n-1] + 1
                sequences[n - sequences[n-1]] = sequences[n]
            else:
                sequences[n] = 1
                
        return max(sequences.values())
```
