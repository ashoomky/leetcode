basically initialise the first window and keep count of the frequency of each character within that window first in an array. indexing is done through minusing ord('a'), e.g. the character ord('a') - ord('a') will give us 0, which is the right index for the frequency of that character to increment.

then, we find the matches. first we check through the entire frequency array, and if the frequency count of the specific index in s1 is the same as s2, then increment matches by 1. if not then just leave it.

then, we do the sliding window algorithm. we initialise the left pointer to 0, and have a for loop for the right pointer. we start the range from the end of the length of the first sliding window we initially initialised to the end of the length of s2. we first check the edge case, if matches is equal to 26 then just return because that means they all match. now we then check the counter for s1 compared to s2. obtain index using method above, then increment the frequency count of s2 for that letter by 1. if the counter for that character in s1 is equal to the counter in s2, then increment. else, decrement from matches by 1. 
do the same except reverse for left pointer (decrement counter from s2.)
then increment left pointer as we are having a fixed window this entire time, and return matches == 26 to see if it is true.
```python
class Solution(object):
    def checkInclusion(self, s1, s2):
        """
        :type s1: str
        :type s2: str
        :rtype: bool
        """
        if len(s1) > len(s2):
            return False

        frequency_s1 = [0] * 26
        frequency_s2 = [0] * 26
        for i in range(len(s1)):
            frequency_s1[ord(s1[i]) - ord('a')] += 1
            frequency_s2[ord(s2[i]) - ord('a')] += 1

        matches = 0
        for i in range(26):
            if frequency_s1[i] == frequency_s2[i]:
                matches += 1
          
        
        l = 0
        for r in range(len(s1), len(s2)):
            if matches == 26:
                return True
            
            index = ord(s2[r]) - ord('a')
            frequency_s2[index] += 1
            if frequency_s2[index] == frequency_s1[index]:
                matches += 1
            elif frequency_s2[index] == frequency_s1[index] + 1:
                matches -= 1

            index = ord(s2[l]) - ord('a')
            frequency_s2[index] -= 1
            if frequency_s2[index] == frequency_s1[index]:
                matches += 1
            elif frequency_s2[index] == frequency_s1[index] - 1:
                matches -= 1
            l += 1
        return matches == 26
```
