daily temperatures
problem: return an array where each index value is the number of days you have to wait to get to a warmer temperature

i know that a monotonic stack must be used for this question except i don't know what a monotonic stack is so i'm going to search it up.
okay a monotonic stack maintains elements in a consistent order, either strictly increasing or strictly decreasing. when a new element is added, elements are popped off from the top if they violate the stack's monotonic property until the property is restored, then new element is pushed. 
apparently monotonic stacks are useful for problems where you have to find the next largest or smallest element for each item in the sequence, which is exactly what we are doing right now.

using a decreasing monotonic stack, i can go through the input temperatures array and compare the current element to the top of the stack element. if it is less than the current stack value, i can pop the top values until i find a value where my current element is greater than or equal to the top most element, then push it to the stack then push the rest of my values. this means that the greatest temperatures should be at the bottom of the stack, and the least temperatures should be near the top of the stack

i can keep track of the index of the temperature in the stack so its easier to access its order and how far away it may be to the next greatest temperature.

however you would need to go through the stack elements continuously to make sure that you insert it at the right place. so how can that not be O(n^2) runtime?

folded and looked at solution because what the heck.

okay so basically you can use a while loop in the for loop to check for each element as long as the current temperature we're on is greater than the top stack temperatures. we store the index and temperature as a tuple in the stack, so we can access both the index and the value to calculate how far away it is, and also to check whether it's greater than. to calculate the difference, we minus the stack's temperature index from the current index (the greater temperature) so we can see the difference. then append the current temperature and its index to the stack so it can get the difference for that temperature too.

```python
class Solution(object):
    def dailyTemperatures(self, temperatures):
        """
        :type temperatures: List[int]
        :rtype: List[int]
        """
        
        stack = [] # store as pair: (temp, index)
        result = [0] * len(temperatures)
        for index, temp in enumerate(temperatures):
            while stack and temp > stack[-1][0]:
                stack_temp, stack_index = stack.pop()
                result[stack_index] = index - stack_index
            stack.append((temp, index))
        return result
```
