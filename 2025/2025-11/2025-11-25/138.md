the solution also made a hashmap. they also made a copy of the list in place. first pass only duplicates each node, doesn't link them yet.
well that solution was simpler than i thought.

basically in the first pass, you duplicate all the nodes and store in a hashmap where the key is the original current, and the value is the copy of the original current.
then, in the second pass you iterate through the list again and access the current node (but the copy of it) through the hashmap. then assign the pointers next and random through the hashmap again, as it gives us the exact value it is related to. 

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, x, next=None, random=None):
        self.val = int(x)
        self.next = next
        self.random = random
"""

class Solution(object):
    def copyRandomList(self, head):
        """
        :type head: Node
        :rtype: Node
        """
        old_to_copy = {None: None}

        # creating copies of all nodes
        current = head
        while current :
            copy = Node(current.val)
            old_to_copy[current] = copy
            current = current.next
            
        current = head
        while current:
            copy = old_to_copy[current]
            copy.next = old_to_copy[current.next]
            copy.random = old_to_copy[current.random]
            current = current.next
        return old_to_copy[head]
```
