looked at the solution.
1. make a result array the same length as the input array and initialise all values to 1
2. first calculate the prefix of each element and store it in the result array to the corresponding index. (current index should contain the product of all integers before the current index) - did this by only updating the prefix AFTER setting the current index in array to the current prefix product.
3. second, calculate the postfix, hence the result by going through the result array in reverse. multiply the current index (so should be the last one) by the postfix (which at the start should be 1 because there's nothing after the last element), which voila gives you the result. keep doing that until reached the end. 

```python
    class Solution(object):
    def productExceptSelf(self, nums):
        """
        :type nums: List[int]
        :rtype: List[int]
        """

        n = len(nums)
        result = [1] * n

        prefix = 1
        for i in range(len(nums)):
            result[i] = prefix
            prefix *= nums[i]
        postfix = 1
        for i in range(len(nums) -1, -1, -1):
            result[i] *= postfix
            postfix *= nums[i] 
        
        return result
```
