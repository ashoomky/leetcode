reverse polish notation!

everytime we get to an operator, we pop the last two values from the stack, perform the operator on it and then append it back to the stack.

forgot to convert string to integer, i did that when appending values to stack so i wouldn't have too much redundant code.

now i have an issue of when i divide 6 / -132, it rounds to -1 instead of 0. which is interesting because 6 / -132 = -0.04545454545 which is so small so i have no idea how it's rounding up to -1. 
i fixed this by first doing the division with absolute values, then using if statements to check whether the result should be - or +.

the time complexity got faster once i changed the division to floor the value and not deal with decimal numbers, which would also give more accurate results.
```python
class Solution(object):
    def evalRPN(self, tokens):
        """
        :type tokens: List[str]
        :rtype: int
        """
        stack = []

        for n in tokens:
            if n != '+' and n != '-' and n != '*' and n != '/':
                stack.append(int(n))
            elif n == '+':
                first_val = stack.pop()
                second_val = stack.pop()
                result = int(first_val) + int(second_val)
                stack.append(result)
            elif n == '-':
                first_val = stack.pop()
                second_val = stack.pop()
                result = second_val - first_val
                stack.append(result)
            elif n == '*':
                first_val = stack.pop()
                second_val = stack.pop()
                result = int(first_val) * int(second_val)
                stack.append(result)
            elif n == '/':
                first_val = stack.pop()
                second_val = stack.pop()
                result = abs(second_val) // abs(first_val)
                if first_val <0 and second_val<0:
                    result = result
                elif first_val < 0 or second_val < 0:
                    result = -result
                stack.append(result)
        

     
        return int(stack.pop())
```
